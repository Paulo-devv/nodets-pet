# Pets

Este projeto é uma aplicação web que exibe informações sobre diferentes tipos de pets (cães, gatos e peixes). Desenvolvida com **Express.js**, a aplicação renderiza páginas dinâmicas com base nos tipos de animais.

## Tecnologias Utilizadas

- **Node.js**
- **Express.js** (framework web)
- **TypeScript** (para tipagem estática)
- **HTML/CSS** (para a estrutura e estilo das páginas)

## Funcionalidades

- **Página Inicial**: Exibe todos os pets cadastrados.
- **Filtrar por Tipo**: Permite visualizar pets filtrados por tipo (cães, gatos e peixes).
- **Renderização Dinâmica**: Utiliza templates para renderizar páginas com informações sobre os pets.

## Estrutura do Código

### Controladores

Os controladores são responsáveis por gerenciar as requisições e as respostas da aplicação. Abaixo estão os principais controladores implementados:

- **home**: Renderiza a página inicial com todos os pets.
- **dogs**: Renderiza a página com apenas os cães.
- **cats**: Renderiza a página com apenas os gatos.
- **fishes**: Renderiza a página com apenas os peixes.
